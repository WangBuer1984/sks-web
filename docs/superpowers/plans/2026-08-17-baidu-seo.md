# 百度可发现性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让百度不执行 JS 也能认出「随口说」官网：真 `robots.txt` / `sitemap.xml`、首页 meta + `<noscript>`、落地页备案号。

**Architecture:** 不走 SSR。Vite 会把 `public/` 原样拷到 `dist/`，sks-web 的 nginx `try_files $uri $uri/ /index.html` 因此会先命中这两个静态文件，不再把 `/robots.txt` 落到 SPA。爬虫正文写在 `index.html` 的 meta 与 `<noscript>`；备案号只加在 `Landing.tsx` 页脚。生产域名写死，不加 `VITE_`。

**Tech Stack:** React 18 + Vite + TypeScript + Vitest（`src/**/*.test.ts(x)`；组件测文件头声明 jsdom）。规格：`docs/superpowers/specs/2026-08-17-baidu-seo-design.md`。

## Global Constraints

- 无任何运行期/构建期 env，禁止 `VITE_`；域名写死 `https://suikoushuo.com/`
- 纸感色板：页脚备案用现有 `text-meta text-paper-mutedLight`，不用主色按钮
- 不改 `prototypes/`、不改 `sks-agent` 网关、不做 SSR、不写百度验证 token
- 测试必须落在 `src/**/*.test.ts` 或 `src/**/*.test.tsx`（见 `vitest.config.ts` 的 `include`）
- 文案与规格逐字一致，不要改写成「差不多」的句子

## File Structure

| 文件 | 职责 |
|---|---|
| `public/robots.txt` | 抓取规则 + sitemap 地址 |
| `public/sitemap.xml` | 仅首页一条 |
| `index.html` | title / description / keywords / canonical / noscript |
| `src/seo/crawler-shell.test.ts` | 读仓库根上的上述三个文件，断言规格字符串 |
| `src/pages/Landing.tsx` | 落地页页脚备案链接 |
| `src/pages/Landing.test.tsx` | 备案链接可见、href/target/rel 正确；微信行仍在 |

- [ ] **Step 1: Write the failing test**

创建 `src/seo/crawler-shell.test.ts`（默认 node 环境，不要 jsdom）：

```ts
import { readFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { describe, expect, it } from 'vitest';

function repoRoot(): string {
  return join(dirname(fileURLToPath(import.meta.url)), '../..');
}

function readRepo(...parts: string[]): string {
  return readFileSync(join(repoRoot(), ...parts), 'utf8');
}

describe('crawler shell files', () => {
  it('serves a real robots.txt for Baidu', () => {
    const text = readRepo('public', 'robots.txt');
    expect(text).toContain('User-agent: *');
    expect(text).toContain('Allow: /');
    expect(text).toContain('Disallow: /admin');
    expect(text).toContain('Disallow: /admin/');
    expect(text).toContain('Sitemap: https://suikoushuo.com/sitemap.xml');
    expect(text).not.toContain('<html');
  });

  it('lists only the homepage in sitemap.xml', () => {
    const xml = readRepo('public', 'sitemap.xml');
    expect(xml).toContain('<?xml version="1.0" encoding="UTF-8"?>');
    expect(xml).toContain('https://suikoushuo.com/');
    expect(xml).toContain('<changefreq>weekly</changefreq>');
    expect(xml).toContain('<priority>1.0</priority>');
    expect(xml).not.toContain('/login');
    expect(xml).not.toContain('/admin');
    expect(xml).not.toContain('<html');
  });
});
```
