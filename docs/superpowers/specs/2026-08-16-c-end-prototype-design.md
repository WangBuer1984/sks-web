## 2. 整体骨架（维持现状）

### 2.1 产品层

- 未登录：落地页（自己的顶栏 + 登录）。登录、开通引导、充值是对话框。
- 登录后：216px 暖炭侧栏 + 主区滚动，没有业务顶栏。

### 2.2 侧栏

| 项 | 去向 |
|---|---|
| 工作台 | 工作台 |
| 账号定位 | 定位页（七字段 + FAQ） |
| 选题库 | 选题库 |
| 文案创作 | 创作页 |
| 对标拆解 | 拆解页 |
| 知识库 | 知识库 |
| 发布复盘 | 复盘页 |
| 额度卡 | 充值对话框 |
| 「新账号视角（演示）」 | 现有开关，只切「空账号 / 王姐演示」，不扩 |
| 头像 | 个人中心 |
| 退出 | 回落地页 |

校准不进侧栏：工作台空态或定位页未校准引导进入，走完回定位页。

### 2.3 两页不要合成

- **账号定位**：未校准引导 / 已校准档案 + 高频问答。
- **个人中心**：完善度 + 资料表单 + 手机换绑。完善度只算昵称 / 行业 / 身份 / 出镜风格 / 每周更新目标；性别、年龄、城市不计入。定位七字段不计入这条完善度。

### 2.4 演示开关

现有「新账号视角」只做两档：

| 档 | 含义 |
|---|---|
| 开 | 未校准、额度过户、选题 / 知识库 / 复盘皆空（老原型 `homeNew`） |
| 关 | 王姐演示数据（老原型 `homeNormal`） |

额度用尽、爆款降级等靠页内点出来，不为它们加开关。

## 4. 各页：布局跟老原型，规则跟 D18–D21

### 4.1 落地页

五段结构不动。文案按新产品改（老原型里已有一部分，对齐下列口径）：

1. 聊 15 分钟，留下定位档案。  
2. 选题从三处来：确认过的客户问答、对标 TOP10、爆款续集。不提热点监控。  
3. 一句话，两个平台，扣 1 条；点采用才进知识库。不提事实卡、小红书、三平台。  
4. 登记只存链接，点「复盘」才抓数；不自动出周报。

技术卡：知识库 = 定位档案 + 写过的口播稿，整篇检索、参考可点回原文。去掉「自动监控」语气。

价格三卡和充值**不是同一套 SKU**：落地页体验 = 免费 + 首充送 10 条；充值是 50 条 ¥49 / 150 条 ¥129 / 拆账号 1 次 = 10 条。不要把 ¥49 印到体验卡上。

### 4.2 登录、开通、充值

维持老原型两步登录对话框 + 开通引导 + 充值档位芯片。全站暂不支持在线支付。

### 4.3 工作台

**布局维持老原型**：问候 +（新账号三步卡 / 已校准三数字 + 选题建议 + 知识库提示条）。不加「最近内容」「待复盘」。

只改口径和旧说法：

- 三个数字改为：知识库内容篇数、待用选题、本周已采用（不要「本周生成 / 采用率」）。  
- 选题建议来源只写 FAQ / 对标 / 复盘，去掉「客户咨询频率第 N」。  
- 知识库提示改为「点采用当前平台版才会存进去」，不要「直接采用」。  
- 三步卡里不要写「换个角度免费」。

### 4.4 校准

三步维持老原型。中途退出不保存。完成后回**账号定位**（不是合成页）。

第 3 步若已有 FAQ 候选：默认全不勾，不勾也能完成。没有这块就补一个轻量勾选，不要重做向导布局。

### 4.5 账号定位

布局维持（档案卡 + 对话回放）。补 D20：高频问答列表（增删改排序，每条「生成选题」）。没有单独 FAQ 区就在档案下方加一块，不要改成两栏重排。

七字段：人设 / 目标人群 / 差异化 / 转化路径 / 口吻 / 红线 / 内容支柱。老原型缺的口吻、红线补进现有卡片网格，不要新开一页。

AI 不能悄悄改档案。复盘后的口吻/红线建议以条幅出现，必须点「采纳建议」才写入；「忽略」不改档案。FAQ 每条可编辑、↑↓ 排序（不必真拖）。问题必填，答案可后补。删除问答或知识库内容都要再确认一次。

### 4.6 个人中心

布局维持。完善度口径改成只算 5 项，页上写明。换绑维持现有按钮（原型可用 toast，不必新做验证码全态）。

### 4.7 选题库

来源三路：FAQ 点过「生成选题」、对标存下来的、复盘续集。没有「拉取今日热点」。

FAQ 已删：选题还在，标「原问答已删除」。刚生成的那条可以高亮或置顶。

### 4.8 文案创作

**布局维持老原型两栏**：左 = 选题 + 时长 + 生成 + 平台页签 + 正文 + 三按钮；**右 = 人设声音 + 参考**。不要把人设挪到输入框上方。

规则改到现有控件上：

- 时长芯片：45 秒口播 / 90 秒 / 3 分钟深度 / 5 分钟，默认 45 秒。  
- 一次生成扣 1 条，含抖音 / 视频号；第一次切视频号若还没出稿，提示「不另扣额度」。  
- 按钮写「采用抖音版」或「采用视频号版」（不要「直接采用」）。采用 = 该平台版入知识库（D14），按钮变「已采用」，重复点不增。只生成、只复制不入库（D15）。  
- 查重：正文上方非阻断提示，可换角度或继续采用。  
- 知识库「去创作页改」打开同一篇，主按钮「保存回知识库」，不扣费。  
- 换个角度扣 1 条。没有小红书。  
- 未校准：右栏人设区「去校准定位」。  
- 参考：生成前「知识库可参考 N 篇」；生成后列整篇；无关选题写「本稿只基于你的定位档案」。同组两个平台版最多参考一篇，优先当前平台（脚注即可，不必画出内部 ID）。

### 4.9 对标拆解

两页签维持。没有「监控中的账号」。深拆在本页展开四字段，不跳详情态。仿写带框架去创作；存入选题库后「已存入 / 去选题库」。

### 4.10 知识库

内容列表维持。来源标签只叫「平台生成 / 我传的」。每条再带平台标签（抖音 / 视频号；手建未登记可空）。未发布或已发布都可以「登记发布」（只存平台+链接，同一篇可再登记另一平台）。链接和所选平台对不上时，再点一次才确认。爆款只能复盘判出。

### 4.11 发布复盘

登记与复盘分开维持。待发布 = 库里还没有登记记录的内容。没有「未采用」行。周报只手动「生成本周复盘」。爆款点「重新抓数据」若不再是爆款，知识库同一条按发布记录最高态重算（无 hot 则回到已发布）。续集选题不重复造。复盘归因可以出改口吻建议，但必须到定位页确认后才写入，不能写「已写入创作偏好」。

## 5. 怎么验收（不再用审查条格子表）

用浏览器打开 07191700，走这些主路径即可。空态靠「新账号视角」；其余靠页内点击。

1. 落地页卖点不再出现热点监控 / 事实卡 / 自动追踪 / 小红书 / 三平台。  
2. 新账号视角：工作台三步、各库空；关掉后是王姐数据。  
3. 定位页能维护 FAQ（增删改、↑↓）并「生成选题」；选题库出现该条且刚生成的可辨认。口吻建议条「采纳 / 忽略」。  
4. 创作：一轮扣 1 条 → 切视频号不另扣 → 「采用抖音版 / 采用视频号版」各入一篇，知识库带对应平台标签。  
5. 知识库未发布可「登记发布」；链接与平台不一致须再确认；点「复盘」才出五码。  
6. 人设在右栏，和定位同一份；取消不保存。  
7. 全站创作/登记没有小红书；选题库没有「拉取今日热点」。
