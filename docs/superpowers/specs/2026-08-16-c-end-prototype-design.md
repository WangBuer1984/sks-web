## 2. 整体骨架

### 2.1 两层

1. **产品层**  
   - 未登录：落地页。落地页在审查条下面仍有自己的产品顶栏（Logo + 锚点 + 登录）。登录、开通引导、充值是叠在产品上的对话框，不是侧栏项。  
   - 登录后：左侧栏 216px 暖炭底 + 主区滚动。登录后的产品区**不再另做一条业务顶栏**，避免和审查条抢位置。
2. **审查条**  
   窗口最顶上一根细条，标明「原型审查 · 不会出现在正式产品里」。  
   - 左：切页面（落地页、登录、充值）。开通引导不是独立页，是登录对话框的第二步，列在 §5「登录」状态下。  
   - 中：切这一页的状态  
   - 右：切**账号阶段**（影响全站空态，见 §2.4）

审查条不是产品的一部分。实现计划里必须写明：React 对齐时丢掉审查条。

### 2.2 侧栏

七项导航（原先的「账号定位」更名为「账号」，个人中心不再单独成页）+ 底栏额度 + 头像：

| 项 | 去向 |
|---|---|
| 工作台 | 工作台 |
| 账号 | 账号页，默认「定位」页签 |
| 选题库 | 选题库 |
| 文案创作 | 创作页 |
| 对标拆解 | 拆解页 |
| 知识库 | 知识库 |
| 发布复盘 | 复盘页 |
| 额度卡 | 打开充值对话框 |
| 头像 | 账号页，打开「资料」页签 |
| 退出登录 | 只在侧栏，回到落地页（原型里不必真清 token） |

**校准对话不进侧栏。** 它是新账号向导，从工作台空态或账号「定位」未校准引导进入；走完回到账号「定位」。

### 2.3 账号页（定位 + 资料合成）

原来的「账号定位」和「个人中心」合成一页，两个页签：

- **定位**：未校准引导 / 已校准七字段 + 高频问答  
- **资料**：完善度 + 账号表单 + 手机换绑  

完善度仍只按昵称 / 行业 / 身份 / 出镜风格 / 每周更新目标这 5 项；性别、年龄、城市不计入。定位档案的七字段不计入这条完善度——校准状态用「已校准 / 未校准」单独表达。

### 2.4 账号阶段（审查条总开关）

| 阶段 | 全站含义 |
|---|---|
| 刚开通 | 未校准；额度过户；选题 / 知识库 / 复盘皆空 |
| 已校准但还没写过 | 档案在；FAQ 可有可无；选题 / 知识库 / 复盘仍空 |
| 使用中 | 各库有内容，可演示爆款、待复盘、FAQ 已删等 |
| 额度用尽 | 内容可在；生成类、拆账号走到「额度不够」 |

切阶段时，当前页立刻换成该阶段下的合理默认态（例如刚开通 + 工作台 = 三步引导）。

## 4. 各页产品

### 4.1 落地页

五段：顶栏（功能 / 技术 / 价格锚点 + 登录）/ Hero / 四个环节 / 技术 / 价格。

四个环节文案：

1. **聊 15 分钟，留下定位档案** — 人设、人群、口吻、红线、支柱。  
2. **选题从三处来** — 你确认过的客户问答、对标账号 TOP10、爆款复盘后的续集。不提热点监控。  
3. **一句话，两个平台，扣 1 条** — 按你写过的整篇内容检索；点采用才进知识库。不提事实卡、小红书、三平台。  
4. **登记只存链接，你点复盘才抓数** — 爆款留下续集选题；不自动出周报。

技术三卡：多模型调度保留；知识库改为「定位档案 + 你写过的口播稿 = 账号大脑，整篇检索、参考可点回原文」；Skill 工作流保留，去掉「自动监控」语气。

价格三卡和充值对话框**不是同一套 SKU**，画的时候不要合成：

- 落地页：体验（标「免费」，注「首充送 10 条」）/ 150 条 ¥129 / 拆账号 = 10 条额度（这张是消耗说明，不是售价）。  
- 充值对话框见 §4.2：50 条 ¥49 / 150 条 ¥129 / 拆账号 1 次 = 10 条。  

「体验」是免费钩子，不是 50 条 ¥49 那一档。只有「150 条 ¥129」两页数字相同。CTA 打开登录。

### 4.2 登录、开通、充值

- 登录对话框两步：手机号 + 验证码 → 新用户看到开通额度引导；老用户直接进工作台。  
- 全站暂不支持在线支付。  
- 充值对话框：「联系我开通」+ 备注手机尾号 + 微信二维码占位 + 档位芯片（50 条 / ¥49，150 条 / ¥129 高亮，拆账号 1 次 = 10 条）+「知道了」。

### 4.3 工作台

额度大卡不出现在本页（只在侧栏）。

- **刚开通**：问候 + 三步引导（校准定位 → 拆一条对标或确认 FAQ → 去写第一篇），主按钮「开始校准」。不出现最近内容 / 待复盘。  
- **已校准之后**（含还没写过、使用中）：问候 + 三个数字（知识库内容篇数、待用选题、本周已采用）+ 「今天可以拍」列表（FAQ / 对标 / 复盘续集，无每日热点）+ **最近内容**（最近 3 篇：标题、平台、未发布/已发布/爆款）+ **待复盘**（已登记未复盘：标题、平台、链接缩写）。后两块在空的时候也占位，文案「还没有」。  
- 额度用尽：生成类入口仍在，点了走额度不够。

### 4.4 校准

三步，中途退出不保存。

1. 贴主页或作品链接。  
2. 一问一答；人设猜错可点「不太对」。  
3. 确认七字段档案；勾选要留下的客户问答（**默认全不勾**，不勾也能完成）。

完成后进入账号「定位」。无流式，进行中用阶段进度。

### 4.5 账号 · 定位

- 未校准：引导 +「开始校准」。  
- 已校准：七字段（人设 / 目标人群 / 差异化 / 转化路径 / 口吻 / 红线 / 内容支柱）+ 高频问答（增删改排序，每条「生成选题」）。  
- AI 不能悄悄改档案。点取消，字段和问答都回到打开页时的样子。保存中、保存失败是 §5 的两格，失败时字段仍是用户刚改的，不回滚。

### 4.6 账号 · 资料

左：完善度条（只算 5 项，页上写明口径）+ 表单（昵称、性别、年龄、城市、行业、身份、出镜风格三选一、每周更新目标）。  
右：手机号换绑。  
保存失败、验证码错、加载失败均可从审查条切到。

### 4.7 选题库

来源只有三路：定位里点过「生成选题」的问答、对标拆解存下来的、复盘爆款续集。没有「拉取今日热点」，列表不会自己变长。

每条可进创作。来自问答且原 FAQ 已删的，选题还在，标「原问答已删除」。刚从定位点「生成选题」进来时，该条高亮或置顶，表示生成成功——这就是 §5「刚从 FAQ 生成」那一格。

### 4.8 文案创作

常驻两栏：

- **左，自上而下**：人设声音（人设 / 口吻 / 红线，与定位同一份；取消不保存）→ 一句话选题 + 时长芯片 → 生成 → 抖音 / 视频号页签 → 正文 → 底部三按钮（采用当前平台版 / 换个角度 / 复制全文）。  
- **右**：只放参考。生成前：「知识库可参考 N 篇」。生成后：命中的整篇，可点回原文；无关选题写「本稿只基于你的定位档案」。

界面上能看见的规则：

- 一次生成扣 1 条，含两个平台；第一次切到视频号若还没生成，提示「不另扣额度」并出稿。  
- **采用 = 该平台版写入知识库**（来源「平台生成」、状态「未发布」，同 D14）。按钮变为「已采用」，同一平台版本重复点不新增一篇。只生成不采用、只复制，知识库都不增加（D15）。§5「采用成功」就是当前平台按钮已是「已采用」、知识库多出这一篇。  
- 生成结果与知识库里已有内容过于相似时，正文上方出一条**非阻断**提示（「这篇和《某篇标题》相似度高，可换个角度或继续采用」）。不挡住采用、不另扣额度。这就是 §5「查重提示」那一格。  
- 从知识库「去创作页改」打开同一篇，保存不新开、不扣费；主按钮改为「保存回知识库」。  
- 换个角度 = 新一轮，扣 1 条。  
- 没有小红书。  
- 未校准：人设区改为「去校准定位」；仍可生成通用稿。  
- 无流式，生成中用阶段进度遮罩。

### 4.9 对标拆解

两个页签，一次性动作，没有「监控中的账号」。

- **拆账号**：贴主页，扣 10 条，出画像对比 + TOP10。深拆在本页展开四字段（结构 / 为什么爆 / 框架 / 和你的差异），不跳详情态。  
- **拆视频**：贴链接或粘文案，出同一套四字段。「用这个框架仿写」带框架去创作；「存入选题库」成功后变成「已存入 / 去选题库」。

本 HTML **不画**视频文案详情态、不预填 `/analyze?video=`、不画全文沉底折叠。那一块继续以已有详情原型和规格为准。

### 4.10 知识库

内容列表。来源标签只有两种：**平台生成** / **我传的**（粘贴或手写保存的都叫这个，不另叫「手建」）。状态（未发布 / 已发布 / 爆款）分开筛。页头「共 N 篇 · 爆款 M 篇」。

- 动作叫「新建内容」：Markdown（标题 + 正文），保存后来源=我传的。  
- 我传的在库里改、删；平台生成的稿点「去创作页改」。  
- 任意来源都能「登记发布」：只选抖音或视频号 + 贴链接，不抓数。一篇可登多个平台。  
- 爆款只能由复盘判出，不能手勾。知识库总状态取最高级（任一发布记录爆款 → 爆款，否则有记录 → 已发布）。  
- 空态两个按钮：去创作 / 把旧文案粘进来（进「新建内容」）。

### 4.11 发布复盘

- 待发布 = 知识库里还没有登记记录的内容（来源可以是「平台生成」或「我传的」）。  
- 已登记的行有「复盘」，点了才出五码和普通 / 爆款。  
- 爆款降级：知识库标签按所有发布记录的最新最高态重算；原续集选题保留，不重复创建。  
- 没有「未采用」行，没有自动周报；只有手动「生成本周复盘」。

## 5. 审查条：页 × 状态目录

实现时每一格都要能切到，缺一格不算做完。

| 页面 | 状态 |
|---|---|
| 落地页 | 默认 |
| 登录 | 填手机 / 倒计时 / 验证码错 / 开通引导 |
| 充值 | 默认说明 |
| 工作台 | 刚开通引导 / 已校准空库（数字 0 + 两块「还没有」）/ 使用中 / 加载 / 失败 / 额度用尽 |
| 校准 | 步骤 1 / 步骤 2 / 步骤 3 / 进行中 / 失败 / 完成确认 |
| 账号 · 定位 | 未校准 / 档案在 FAQ 空 / 有 FAQ / 保存中 / 保存失败 |
| 账号 · 资料 | 完善度未满 / 已满 / 保存中 / 保存失败 / 换绑 / 换绑验证码错 / 加载 / 加载失败 |
| 选题库 | 空 / 加载 / 失败 / 有选题 / 刚从 FAQ 生成 / 含「原问答已删除」 |
| 文案创作 | 未校准 / 空态 / 生成中 / 失败 / 额度不够 / 只有抖音版 / 两版都在 / 查重提示 / 无关选题无参考 / 改已有稿 / 采用成功 |
| 对标拆解 | 空 / 进行中 / 失败 / 额度不够 / 账号结果 / 视频结果 / 已存入选题 |
| 知识库 | 空 / 加载 / 失败 / 有内容 / 筛选后为空 / 新建编辑 / 登记弹窗 |
| 发布复盘 | 待发布空 / 已登记未复盘 / 已复盘 / 爆款降级 / 周报空 / 周报生成中 / 有周报 |

账号阶段与页状态同时生效时，以页状态为准（例如强制切「创作 · 额度不够」时，不必先把阶段拨到额度用尽）。

## 6. 视觉约定

- 底 `#f4f1e9`，主色 `#8a5a2b`，侧栏暖炭，标题 `Noto Serif SC`。  
- 比旧导出件更疏、更整齐：主区最大宽度约 880–1120，卡片圆角与现网 `rounded-card` 一档，正文不用半像素字号堆砌。  
- 空态用一句人话 + 一个主按钮，不用插画墙。  
- 加载用阶段文案或脉冲条，不用骨架屏迷宫。  
- 危险操作（删除内容、退出校准）用确认条，不要浏览器原生 `alert`。  
- 审查条视觉必须能一眼和产品区分开（深底或虚线纸边 +「原型审查」字样），高度约 36–40px，不挡侧栏品牌名。
